## 打开与操作

可直接访问[在线研究 Demo](https://thisisyk.github.io/sidewalk-delivery-robot-research/)，无需安装或登录。公开网页只播放已保存的八场景合成轨迹与模型评分；可切换场景、播放、暂停、拖动、调节播放速度、改变观察视角及查看已记录的协助指令。需要重新推理的参数在静态模式下禁用，避免把未发生的计算显示成新结果。自定义密度、车队、阈值或处理方案时，使用下文的本地服务。

直接打开 [`demo/index.html`](../demo/index.html)。它只读取同目录的 `sidewalk_gallery.js`，默认从“密集人群·步道相遇”的首帧开始播放，不自动跳到协助或成功时刻；缺少该文件时明确报错，不会回退旧道路动画。

- 选择十字路口、步道转角、建筑盲角、T字路口、垃圾、施工、人群或综合街角，共八个预计算场景。
- 默认自动播放，可暂停、重播、拖动进度及改变播放速度。系统启用“减少动态”时点击“开始动画”。
- “全场真值”包含模型当前不可见的目标，以淡色/虚线区分；“主机器人观测/已知地图”只显示当前可见目标、先验建筑及已发现的静态物。
- 浅绿是人行道，灰色是机动车道，斑马线连接步道；小箱体六轮图标是机器人，较大车体是汽车。
- 行人按保存帧中的同ID坐标实际移动，位置与航向平滑插值。摆腿和方向箭头仅辅助阅读，不产生轨迹；模型分数保持原帧值，不做插补。

离线切换场景只加载已计算回放。修改阈值、人数、密度、遮挡或机器人数量后重新调用模型，需要本地Python服务；离线回放会恢复该预设的真实参数，不伪装参数重算。

## 本地服务

安装项目依赖后，可直接加载本次补充发布的冻结配置模型，**无需下载原始Waymo数据或重新训练**。先核对[模型清单](../models/frozen_histgb_seed42.manifest.json)，确认文件来自可信发布，并阅读[模型用途与许可](../models/README.md)：

```text
python scripts/serve_demo.py --model-artifact models/frozen_histgb_seed42.joblib --model-manifest models/frozen_histgb_seed42.manifest.json --trust-model-artifact --port 8766
```

`joblib`反序列化可能执行代码，必须只加载可信来源。哈希用于核对已知发布文件，不能让未知或恶意文件变得安全；`--trust-model-artifact`是显式确认。依赖版本按项目 `requirements.txt`，其中scikit-learn为1.7.2。

已有合法提取数据时，也保留从同一冻结配置拟合的原路径：

```text
python scripts/serve_demo.py --samples artifacts/prepared/samples.csv --port 8766
```

然后打开 `http://127.0.0.1:8766/`。服务只监听本机回环地址，无外部API、上传或收费。界面默认人群场景、6台机器人、1名模拟协助员、种子42、120秒；运行域固定 `robot`，不提供沿车道纵行的汽车/机器人切换。可选12/24台、行人与来车密度0.5/1/1.5倍，并开关建筑视线遮挡作机制对照。

默认仍使用原开发集阈值0.95568571118795，它没有在机器人数据上重新校准。改变阈值属于探索演示，不是选择了新的最优部署阈值。

## 确保用的是学出来的算法

`demo_model.py`按原特征顺序使用194列，只在原训练集857例上重新拟合同一全特征HistGradientBoosting（seed42），不重新选模。训练不使用开发或评估样本，评估数据只在拟合后做一致性审计。206个原评估分数的最大绝对差为1.11×10⁻¹⁶，AP重现为0.7302762063131997，详见[模型一致性记录](../results/simulation/model_parity.json)。

本次权重导出沿用该冻结配置，并单独记录保存/加载核验、文件SHA-256和环境版本，见[模型清单](../models/frozen_histgb_seed42.manifest.json)。加载模型文件不会重训或重新选模；原运行清单的 `no_weights_saved` 只描述当时未保存文件，不代表本次补充发布不存在模型。模型文件包含拟合参数及评分所需元数据，不附原始轨迹、逐场景特征或真实预测表。

模拟器按原评分接口提取当前和过去约一秒的真实观测历史，在满足资格时每秒调用同一模型。逐机器人视线遮挡会屏蔽未见目标，隐藏历史不回填；未来模拟轨迹不进入评分。没有用手写“风险函数”替换模型输出。

**原训练对象是道路汽车，人行道机器人是未经验证的域外迁移。** 机器人在轨迹适配器中使用车辆运动学代理编码，这不代表原模型已经学习过机器人类别。没有垃圾、围挡或建筑的新增训练标签；这些物体交给独立规则层处理。分数不是事故概率、接管概率或经机器人域校准的危险度。已经进入原两米事件阈值时，原主任务不适用，界面显示不评分。

## 请求、运动与人的边界

- **模型高分与行为异常是两个请求通道。** 原高分通道要求受阻至少2秒且有有效高分。新增独立通道不要求有效分数：连续停滞5秒、被静止机器人阻塞2秒，或连续规划失败2次时可以请求。模型没有学过路径规划、转向控制或人工协助需求，新增判断来自工程规则。
- **请求有资源约束。** 模拟采用FIFO，等待队列上限为协助员人数的2倍，全队新请求间隔至少0.5秒；服务后冷却15秒，每台最多3次请求。队满或冷却中仍可能等待，请求不保证获助后到达。这些数值是假设，不是真实运营规则或最优参数。
- **通行域由独立规则约束。** 机器人完整占地必须在步道/斑马线联合区域内，汽车完整占地在机动车道；停车同样不占用人行道。垃圾、材料和围挡可以占用步道，规则层可能绕行、等待或规划失败。
- **行人确实移动。** 他们沿合成步道与斑马线连续运动，并非固定坐标点。当前行人按预设路线运动，没有完整的人机相互避让模型，可能接触已经停止的机器人；该失败会保留。
- **协助是模拟假设。** 先到先服务、15秒协助与许可通行域内的静态路径搜索均为规则，不能据此声称模型学会绕垃圾、识别受阻原因或降低真实人工成本。独立行为请求修复的是“模型无效时无法求助”的系统逻辑，不是原模型预测精度的提升。

机器人图标为可读性略放大；接触与越界使用实际0.9×0.65米旋转矩形。模型输入、运动规则和视觉摆腿是不同层，不以动画看起来顺畅代替实验证据。

## 模拟协助员具体做什么

`assistance.py`把协助处理拆为可检查的指令与执行流程：请求进入FIFO、分配席位、完成15秒处理、下发指令、机器人执行、记录恢复或再次受阻。请求记录保留原因、评分资格、请求/开始/完成时刻、指令、路点及带时间戳的执行状态；服务结束不自动等于任务完成。

| 操作办法 | 机器人之后的操作 | 保留的失败 |
| --- | --- | --- |
| `replan_walkway`：批准步道内重新规划 | 将当前可见静止机器人的完整占地作为临时规划障碍，安装许可步道/斑马线中的新路点，再逐步执行原避障与整机通行域检查 | 再次受阻可以按次数和冷却约束重新求助 |
| `hold_then_resume`：暂停让行后重新检查 | 原地保持3秒，再检查当前观测；允许通过才沿原路线前进 | 不允许穿过行人或机器人，阻挡持续时继续保持或后续求助 |
| `onsite_required`：停车并升级现场处理 | 保持停止，任务标记为需要现场检查/清障 | 不模拟真人到达或障碍消失，不把机器人移动到终点 |

自动规则只使用当前可见目标和已知地图：4米内有移动行人且没有机器人阻挡时选择短时让行，否则尝试许可区域内重规划。保守规划器没找到路径并不证明现实中必然无路。4米范围、3秒保持和服务时长都是工程假设。用户选择操作办法也不能关闭避障或授权进入机动车道。

重新规划时，速度小于0.05米/秒的可见其他机器人按完整占地临时避开；移动或隐藏机器人不冻结为已知静态障碍。新路线下发后必须实际执行原运动检查，不能以路线下发状态声称已经脱困。初版只处理静态地图的协助模块保留为消融，最终16个主策略设置均按修复后的模块重新运行；未改动控制分支仅在来源哈希核对通过后复用旧实跑结果，不能按独立新实验重复计数。

该模块是规则模拟协助员，没有接入真人遥控或语言模型驾驶。请求机制与协助处理同时变更时，必须通过仅改变求助通道的消融区分作用，不能把组合机制的收益全部归因于ML或单一触发条件。

## 同时看完成、接触与越界

主界面保留完整时域完成数、等待、请求和席位占用，同时显示：

| 字段 | 应怎样解释 |
| --- | --- |
| `physical_overlap_frames` | 存在真实矩形接触/重叠的机器人帧；不是独立事故次数，同一接触可累计多帧 |
| `off_walkway_frames` | 机器人完整占地离开许可步道/斑马线的帧数 |
| `cars_off_road_frames` | 汽车含停放车完整占地离开机动车道的帧数 |
| `pedestrians_off_walkway_frames` | 行人完整占地离开步道/斑马线的帧数 |
| `unsupported_static_objects` | 原模型没有学习相应类别、由规则处理的建筑/垃圾/围挡数量 |

缺少字段显示“未提供”，不会默认为零。当前接触机器人以红框标记。完成到达任务不等于安全；零越界和零接触也不构成真实安全验证。

原人行道版已出现垃圾/人群导致停滞，以及移动行人接触已停机器人的结果；旧聚合快照保留在 `results/sidewalk_baseline/`。新增机制的配对结果以[人行道报告](sidewalk_demo_zh.md)和 `results/sidewalk/` 为准，不将旧版数值冒充修复后的结果。未完成、接触和规划失败都不会因表现差而删除。

## 当前回放与审计

`sidewalk_gallery.js`保存八场景的合成轨迹、真实模型分数和界面所需字段，不含Waymo真实场景坐标、原始记录或模型权重。生成回放时实际调用原模型；GIF渲染只读取保存帧，不重算模型、不重建缺失人的位置或填补分数。

四联动画为十字路口、盲角、垃圾与综合街角。每张面板使用相同的实际保存时间；输出清单记录源画廊SHA-256、共同帧时间、同ID行人位移统计和域统计原值。独立几何审计从导出的矩形联合域检查完整机体面积，既不只看中心点，也不依赖摆腿动画证明人的位移。

[协助生命周期审计](../results/sidewalk/assistance_audit.json)另行核对请求原因与阈值、时序、队列/席位资源、冷却重试、下发指令及坐标运动。它不导入控制器，不把“路线已下发”当作已经脱困。

使用新目录复现，避免覆盖原运行：

```text
python scripts/verify_demo_model.py --samples artifacts/prepared/samples.csv --output artifacts/model_parity_reproduction.json
python -m unittest discover -s tests -v
python scripts/build_sidewalk_gallery.py --samples artifacts/prepared/samples.csv --output results/sidewalk_reproduction --gallery artifacts/sidewalk_gallery.js
python scripts/audit_sidewalk_gallery.py --gallery artifacts/sidewalk_gallery.js --output results/sidewalk_reproduction/geometry_motion_audit.json
python scripts/audit_assistance_gallery.py --gallery artifacts/sidewalk_gallery.js --output results/sidewalk_reproduction/assistance_audit.json
python scripts/render_sidewalk_animation.py --input artifacts/sidewalk_gallery.js --output artifacts/sidewalk_scenarios.gif
```

软件测试和人工样例只验证代码行为。没有用新增合成场景重新计算原道路评估AP、重新选模或宣称增加了独立真实样本。
