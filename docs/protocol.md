## 研究问题与适用范围

能否仅利用过去可观察的运动状态，对未来三秒的近距离交互代理事件进行排序，并提高固定复核预算下的事件覆盖率？

Waymo 与 Uber Eats 曾开展自动配送合作；本项目研究合作方的公开道路交通数据，不能声称使用了 Uber Eats 实际配送任务、Serve 人行道小车或人工接管日志。[Uber 官方公告](https://www.uber.com/us/en/newsroom/uber-and-waymo-autonomous-deliveries-phoenix/)

## 数据与时间边界

采用 Waymo Open Motion Dataset（WOMD）的 Scenario 格式。标准九秒窗口提供过去一秒、当前帧及未来八秒；本项目只使用过去一秒预测未来三秒。[官方格式说明](https://waymo.com/intl/en-ca/open/data/motion/)

以 `current_time_index` 为唯一预测锚点，不把窗口内其他未来时刻再次作为训练锚点。历史为截至锚点的十一帧，目标区间为随后三十帧。若某版本时间戳不满足这些条件，明确拒绝该样本并记录原因，而非猜测采样频率。

`sdc_track_index` 指定参考车辆。当前可观察、位于参考车辆中心五十米内的车辆、行人、骑行者构成候选集合，按当前距离选至多十六个。没有候选的场景排除并计数，避免必然阴性样本主导交互任务。目标筛选与排序仅使用当前及历史有效状态，不允许按未来距离或未来事件挑选目标。

## 研究标签

主标签为 **未来新发生的近距离交互代理事件**，不等同于事故、驾驶失败或需要人工接管。

根据位置、航向、长宽构建二维旋转矩形。两矩形相交时边界间距为零；否则使用轮廓间最短欧氏距离。主分析阈值 `d = 2 m`，敏感性阈值为 `1 m` 与 `3 m`。对于保留场景：

`y_d = 1[未来三秒内，参考车辆与当前候选集合中任一对象的轮廓间距 <= d]`

规则：

- 当前已存在间距不超过相同阈值的交互时，排除该阈值下的样本，以免把持续接近误当成提前预测。
- 未来真值只用于计算标签、事件时间和事后可视化，不能进入输入特征。
- 采用严格完整覆盖队列：参考车辆或任意一个当前选定对象缺失未来三秒中任意所需测量时，整个场景删失。即使已观测部分出现接近，也不另外保留，以维持一致队列。不能把缺失当成安全。
- 各阈值分别记录原始场景数、历史无效数、当前事件排除数、未来删失数、保留数和正例数。
- 对几何错误、异常尺寸和非有限数值拒绝样本；不以零填充无效真值后生成标签。

该标签采用离散时刻近似，可能遗漏两帧之间的短暂接近。它测量观测到的近距离现象，不衡量反事实碰撞风险。

## 输入与泄漏防护

初始 CPU 实验使用本车运动、相对位置和速度、历史变化、对象类型、候选数量以及恒速外推的几何指标。特征定义以代码生成的清单为准。

- 转换到锚点参考车辆坐标系；使用锚点之前的数据计算历史差分。
- 标准化、缺失值填补和其他可学习变换只在训练集拟合。
- `scenario_id`、文件名及 split 只作元数据。
- 不将未来轨迹、未来有效性掩码、未来信号状态、`objects_of_interest`、`tracks_to_predict` 或 `sdc_paths` 作为模型输入。
- 初始实验包含到静态地图采样顶点的最小距离及邻近要素数量。这是顶点近似，不能声称是到折线/多边形边界的精确距离；不包含 LSTM 或 Transformer，未实现的方法不出现在结果表中。

## 数据划分

训练使用官方 training 数据；官方 validation 文件按预先固定、确定性的 shard 规则分为开发集和锁定评估集。官方 test 隐藏未来真值，不用于本研究标签评价。

选择 shard、样本上限和随机种子均在训练前写入清单。禁止把场景行随机拆入三组。开发集用于模型选择、参数选择和阈值选择；锁定集仅作最终报告，不能反复查看后选择最佳版本。

Scenario 格式没有本项目已经核实可用的原始驾驶日志 ID；shard 分组不能证明同一日志的所有重叠窗口都被分到一起。报告应保留这一局限，不得写成已完成严格日志去重或跨城市泛化测试。

## 对比方法

| 方法 | 定位 |
| --- | --- |
| 恒速外推最小轮廓间距 | 强几何规则基线；使用当前状态预测目标与参考车的位置 |
| Logistic Regression | 线性可解释基线 |
| Random Forest | 非线性树模型 |
| HistGradientBoosting | CPU 可运行的提升树模型 |

所有学习模型使用相同样本划分。初始参数、随机种子和有限搜索空间在配置中保存。不得仅报告表现最好的随机种子。恒速基线的未校准分数用于排序指标；它不能直接作为概率计算校准指标。

## 评价

主指标为 Average Precision（AP，明确区别于梯形积分 PR-AUC）。同时报告正例率、ROC-AUC、固定复核预算 `5% / 10% / 20%` 下的召回率和精确率，以及相对随机筛选的 lift。若使用概率输出，补充 Brier score。

固定预算实验按模型分数选取锁定评估样本中的前 `k=floor(N×预算)` 个，边界平分采用与标签无关的随机选择期望（平分组获得相同分数权重），避免场景排序带来的偏差。这是离线批量复核排序，不能解释为真实车队请求率或在线排队策略。随机筛选的期望召回率等于其实际抽样比例。

开发集确定主模型后，报告所有基线和该主模型的锁定结果。敏感性分析不以锁定集最优阈值重新定义主任务。子组分析报告样本数；正例太少时仅作探索，不给稳定优越性的结论。

在样本充足时，使用预定随机种子的配对自举给出模型差值和指标的百分位区间，并说明抽样单位。它不能消除未识别重叠日志造成的相关性。无正例或无负例导致指标不可定义时写 `NA`，不能填零或删除该组而不说明。
