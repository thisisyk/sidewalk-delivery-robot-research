## 预览与新计算

首次打开先显示“密集人群·步道相遇”的**默认预览**，从首帧播放。这是已保存的合成轨迹和实际模型评分，供计算环境准备时查看。修改表单不立即改变当前轨迹；必须点击“重新计算”，并等计算成功后，画面才代表这一组新参数。

完成后，“计算来源”区域显示实际生效配置、新轨迹帧数、协助记录和运行时间。“模型与计算证据”列出模型与计算清单的SHA-256、Pyodide和NumPy版本，以及 `fresh_simulation: true`、`saved_trajectory_used: false`。新运行从当前参数生成轨迹，不用默认回放替代；计算失败时不会把预览称为新结果。

播放、暂停、重播、拖动、播放速度和观察视角只改变展示。行人按同ID轨迹帧的实际坐标移动，摆腿用于识别；模型评分在实际评分帧间保持原值，不为了动画平滑制造中间分数。

## 可调整的参数

| 参数 | 浏览器选项或范围 | 含义 |
| --- | --- | --- |
| 场景 | 十字路口、步道转角、建筑盲角、T字路口、垃圾占道、施工窄口、密集人群、综合街角 | 八类合成地图和参与者设置 |
| 机器人数量 | 6、12、24台 | 机器人仍仅在人行道与斑马线通行 |
| 模拟协助员 | 1、2、4名 | 影响席位和请求等待，不是真人在线服务 |
| 模型请求阈值 | 滑块0.05—0.99，步长0.01 | 默认保留原开发集精确阈值0.95568571118795，用户调整是探索 |
| 随机种子 | 0—100000的整数 | 固定同一场景的随机生成输入 |
| 行人与来车密度 | 0.5、1、1.5倍 | 汽车仍只在机动车道，行人仍在步道和斑马线移动 |
| 建筑遮挡 | 开启或关闭 | 控制逐机器人可见目标，不回填隐藏历史 |
| 独立行为兜底 | 开启或关闭 | 开启时允许停滞、互堵和规划失败独立求助；工程规则，不是新增训练结果 |
| 模拟协助办法 | 自动、步道内重规划、短时让行再检查、停车升级现场处理 | 不关闭避障或通行域检查，不模拟障碍凭空消失 |
| 模拟时长 | 30、60、120、180秒 | 只改变本次合成实验观察时域，不改变原模型的三秒预测标签 |

先用6台、30秒尝试；更长时域、更多参与者和策略对照可能明显增加计算时间。请求和协助处理后仍可能受阻或未完成，应同时查看完成、等待、请求和矩形接触帧。

“计算全部策略对照”是可选的额外计算。开启兜底时，运行主策略及原纯模型门控、仅新增停滞求助配旧处理器、等待2秒即请求、仅自主等待四个控制分支；关闭兜底时，运行原模型门控及等待规则、自主等待两个控制分支。各分支保持同一场景、种子与其他参数；对照表来自本次实际运行，不把缺少计算的策略补为零。对照结果属于用户配置下的探索模拟，不覆盖仓库已冻结的16设置实验。

## 计算过程和取消

首次加载需要约17 MB的Python/NumPy计算环境，另有页面、默认预览和模型等资源；下载时间受网络影响。这些资源来自完整静态发布站点，无需Google或GitHub登录。浏览器是否复用缓存由自身策略决定，不保证断网即可重新初始化。

计算在独立Web Worker中进行，页面可显示下载、校验、模拟、整理结果等阶段，模拟进度来自已经执行到的模拟秒数。它不是到达率，也不是下载速度或预计剩余时间。策略对照时同时显示当前策略和总策略数。

“取消本次计算”会终止Worker，保留上一组完整结果，不把部分运行当成完整实验。再次计算会重新初始化Worker；可复用的静态资源是否再次下载取决于浏览器缓存。下载、模块或模型校验失败会显示错误，可在网络恢复后重试。

## 与原学习模型的关系

Worker通过Pyodide执行Python与NumPy，加载原场景、历史观测、几何、步道模拟和协助模块。浏览器不重新训练，不加载逐场景真实记录，也不把保存轨迹当作本次计算输入。

浏览器模型由已发布的冻结HistGB权重转换为数据JSON，保留原顺序的194列特征、中位数缺失值填补统计量、初始分数和100棵树的节点与叶值。数值推理按原树序累加后计算logistic分数；不是用手写风险公式替换模型。

| 核对项 | 文件或数值 |
| --- | --- |
| 浏览器模型 | [`demo/frozen_model.json`](../demo/frozen_model.json) |
| 模型JSON SHA-256 | `d14266b9469120bfcc477716ab09d2a01c5bb954a60fc6c76f41c4450968440f` |
| 来源模型 | [`models/frozen_histgb_seed42.joblib`](../models/frozen_histgb_seed42.joblib)，来源与导出核验见[清单](../models/frozen_histgb_seed42.manifest.json) |
| JSON导出程序 | [`scripts/export_browser_model.py`](../scripts/export_browser_model.py)，只转换已有模型，不调用训练 |
| NumPy评分实现 | [`src/delivery_risk/browser_model.py`](../src/delivery_risk/browser_model.py) |
| 浏览器桥接 | [`demo/compute-worker.js`](../demo/compute-worker.js)、[`demo/browser_bootstrap.py`](../demo/browser_bootstrap.py) |

站点构建时生成 `compute-manifest.json`，逐项记录模型、桥接和Python模块的SHA-256；Worker在使用前校验这些资源。校验用于识别与当前发布清单不一致的文件，不代表模型有效性或真实安全已经验证。树转换的一致性软件测试覆盖数值、缺失值、分裂阈值邻域与独立合成历史；它们不能替代真实机器人域的外部验证。

## 本地查看与复现

只想看保存回放，可以直接用 `file://` 打开仓库的 `demo/index.html`，此时显示只读回放。浏览器完整计算需要Worker、WebAssembly和通过HTTP(S)加载的完整站点资源；仅复制HTML或直接打开源码页面不能代替完整发布包。

在仓库根目录构建完整静态站点，并用本机静态文件服务器打开：

```text
python scripts/build_public_demo.py --output artifacts/browser-site
python -m http.server 8767 --bind 127.0.0.1 --directory artifacts/browser-site
```

访问 `http://127.0.0.1:8767/`。输出目录须为空；构建包含固定运行时、JSON模型、Python模块、默认预览和完整许可。该命令只是静态文件服务，推理仍发生在自己的浏览器，无需账号或模型后端。首次使用需让所有资源可被本机浏览器访问。

若使用原Python模型服务，仍按[本地服务指南](demo_guide_zh.md#本地服务)启动。两种入口遵守相同研究与许可限制；浏览器版不会把Waymo原始数据重新分发为网站资源。

## 结果的科学边界

原模型基于道路汽车数据，人行道机器人是未经验证的域外迁移；分数不是事故概率、接管概率或经过机器人域校准的危险度。当前已在两米事件范围内时仍按原资格规则不评分。步道约束、避障、求助与协助均为工程规则，不是模型新学会的控制能力。

浏览器参数试验与预计算机制比较都属于合成环境，不增加原研究的独立真实样本，不改写206例锁定评估的AP与预算结果。模拟时长改变会影响任务是否来得及完成，不能将30秒与180秒的完成数直接解释为策略改善。接触帧不是独立事故次数，零越界和零接触也不构成真实安全证明；不能据此宣称Uber Eats真实成本或接管率改善。完整限制见[研究报告](final_report_zh.md)与[人行道协助报告](sidewalk_demo_zh.md)。
