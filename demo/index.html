在人行道上，机器人如何绕过街角？

机器人与行人走人行道，汽车走机动车道。机器人仅沿步道与斑马线过街，在拐角、垃圾堆、施工与人群场景中观察模型评分、遮挡和规则避障。

研究演示合成场景与模拟协助；道路模型迁移到人行道机器人，未经实地验证。仅限非商业研究 · GitHub 项目 · 完整 Waymo 数据集许可
